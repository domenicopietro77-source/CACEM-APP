# CACEM-APP

Configuratore grafico CACEM per strutture prefabbricate.

## Obiettivo
Un unico modello strutturale genera pianta 2D, sezioni/prospetti, vista 3D, render realtime, distinta elementi ed esportazioni DXF.

## Primo catalogo
- PP2 — Pilastro CACEM
- TL — Trave prefabbricata

Le geometrie definitive dei due elementi verranno sostituite con quelle estratte dai DXF reali CACEM. Il prototipo non considera la geometria procedurale come fonte ufficiale.

## Avvio
```bash
npm install
npm run dev
```
